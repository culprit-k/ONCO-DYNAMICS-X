## First real-cohort benchmark

A paired TCGA-BRCA workflow queries open GDC STAR-count expression metadata for primary tumour and solid-tissue-normal specimens, selects paired patients, downloads selected files with checksum verification, assembles a sample-by-gene TPM matrix and evaluates a patient-grouped tumour-versus-normal logistic-regression baseline. The workflow publishes metadata and metrics only; raw expression files and matrices are not committed or uploaded. See [the analysis protocol](docs/tcga_paired_baseline.md) and [GitHub Actions](https://github.com/culprit-k/ONCO-DYNAMICS-X/actions). This is a technical specimen-label benchmark, not a clinical diagnostic, prognostic or treatment-response model.
