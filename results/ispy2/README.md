# I-SPY 2 aggregate analysis results

This directory contains aggregate-only outputs. Participant identifiers, patient-level rows, source workbooks and the linked workbook are excluded.

- `ispy2_multifeature_aggregate.json`: descriptive four-feature analysis.
- `ispy2_clinical_linkage_and_pcr_aggregate.json`: linkage and exploratory pCR associations.
- `ispy2_pcr_response_model_comparison.json`: locked patient-level linear versus quadratic response model comparison and reaction–diffusion identifiability gate.
