# Optimal control

An optional CasADi mean-field optimal-control demonstration is implemented in mean_field_ocp.py. It optimizes a bounded abstract simulation input for a two-state dimensionless toy ODE. The control variable is not a therapy, drug concentration or dose. It must not be used for patient-specific treatment decisions.

The full coupled PDE control problem remains planned; any objective and constraints need explicit scientific justification and uncertainty analysis.
